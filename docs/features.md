## 功能

- **任务自动化**：五环、客栈、修罗、五倍、种族比武（队伍任务，固定 5 人：长安领取（到达领取点先 Alt+4 完全清屏，再按四外观模板组识别领取 NPC（2026-11-21 用户实机截图新增「昊天」转身姿态模板）——同屏多候选取最右侧、点击前名称 OCR 分选「昊天」——名称只用于从模板候选中选对 NPC，点击点仍取模板中心（长名行会粘行漂移，不用于算点击坐标），同模型侍卫/姿态变化不误点、不点偏、人物坐标须到位才点击）→ 寻路 → 任务对话五选一 → 助威令返程；领取人数不足时任务不出现，自动复查并补人；巫医链路暂未实现）、玄枢轶闻、名望（山河名望：种族判定 + 魔族/仙族领取入口 + 面板领取并执行高级任务；**统一走小地图快捷领取**——打开种族地图小地图（已在目标地图则直接开小地图，否则经世界地图点种族地图标签）→勾选底部「任务」筛选→点击地图上固定位置的黄色任务 NPC 名（魔族 逆天魔 / 仙族 武尊神），游戏自动寻路并在到达后自动打开对话框，直接点绿色选项「开启山河名望志」；不依赖会被玩家/对话框/摊位遮挡的 NPC 模板（旧「坐标寻路 + NPC 模板」路线已移除）），每个任务可独立设置执行次数；任务页为**待选/已选双区**——点击待选卡加入已选（按加入顺序排列）、点已选卡移回待选，**已选任务可拖动「≡」手柄或点 ↑↓ 调整顺序**，启动后按该顺序依次执行、全部完成后自动结束，无需逐个任务重启；任务进度统一展示在运行看板队列（已完成次数 / 次数上限，次数上限为 0 不限的任务不计入）；**任务运行中禁止修改选择/顺序与次数**（只能停止后修改）；当天完成进度按角色持久化，停止/重启不重置
- **任务栏读取与降魔任务识别（2026-11-23 实机验证）**：Alt+Q 静默开关任务栏（面板可拖动，大小固定）；按「任务列表」「任务详情」两条标题条模板动态定位两栏——模板含整条宽度，栏位置与宽度均由模板给出，不写死坐标；关闭走右上角圆形 X 模板（全帧唯一，实测 1.00 / 次高 0.53），失败回退 Alt+Q。任务列表 OCR 找到「降魔任务[1]」分组行，行首展开/折叠图标（展开=日形两格、折叠=田形四格，9x9 仅图标本体模板）双模板比分数判定：目标态 0.97~1.00、另一态 0.80~0.87，按「≥0.90 且领先 0.05」判定（行被选中时行背景变灰，含背景的 12x12 模板会掉到 0.87，故只裁图标本体）；折叠则点击图标并轮询子任务行出现；列表找不到「降魔任务」分组时先 OCR 点击「当前任务」标签页（任务栏会记住上次标签）再重读一次。随后点击分组下第一个子任务（取同行最左文本块，右侧 [√] 标记不参与点击），OCR 任务详情栏并输出「任务目的」段落（至「任务轮次 / 今日已完成 / 任务状态 / 你当前 / 全队当前」等段头为止，置信度 <0.55 的噪声行过滤——实机暗雷任务首行下方曾出现 0.548 的单字碎片）。**降魔任务识别**（`src/device/demon_task.py`，纯文本解析，供五倍手动寻路前置）：击杀类输出地图/坐标/目标（三藏逢魔实测两种变体：四圣庄 163,105 神通魔尊；万寿山 37,11 天眼魔尊）；黄袍怪多轮类（智斗黄袍）输出地图/坐标/目标（如平顶山 302,22 愤怒的黄袍怪，kind=huangpao，供多场战斗复用同一目标；判定只认击杀目标/任务名含「黄袍」，三藏逢魔文案中的「黄袍怪老巢」是叙述不会误判）；暗雷/锁妖网类（殿前献艺）返回 reclaim=True 需重新领取替换；显形镜类（宝象迷情）输出地图 + A/B 两坐标（如平顶山 187,27 / 269,28）+ 显形镜道具模板 `wubei_xianxingjing.png`（用户素材，位于背包-任务储物格）。地图名经 `map.resolve_world_map_name` 繁体/形近归一（平项山→平顶山），坐标兼容全/半角括号逗号与缺右括号，显形镜兼容 OCR 误读「豆形镜」（取「形镜」子串）。面板原位、拖动到 (-52,+51) 位置、折叠/展开两态均实机跑通；限制：目标分组需在任务列表可视区内（未做列表滚动），任务详情超出面板可视高度时只读可见部分（未做详情栏滚动）。

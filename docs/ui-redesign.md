# 控制面板重设计提案（啄木鸟 · 大话2助手）

> 状态：已实施（2026-11-02）。目标读者：本人（设计评审）+ 后续实施会话。
> 实施偏差（按用户反馈调整）：独立吸附日志窗已移除（面板日志抽屉取代）；
> 看板大按钮与顶栏启动重复，已去掉看板按钮；「显示与调试」开关最终放在系统页；
> 名望任务保留可勾选（运行时自动跳过）仅加「规划中」badge；任务页不展示
> 进度（进度只在看板队列）。状态通道 v2 已实施（2026-11-02）：状态文件新增
> 结构化 phase 字段，各任务模块在阶段节点写入、战斗线程进出战斗覆写/清空，
> 看板「阶段」行实时展示（见 README 功能列表的阶段枚举）。
> 设计系统参考：`design-system/default/MASTER.md`（Real-Time/Operations 模式、高密度仪表盘、Subtle 动效）。
> 原则：**不改任何后端设置语义与 callPython 接口**，现有功能全量保留，纯前端重构 + 新增 1 个状态接口。

## 1. 现状问题诊断

| # | 问题 | 现状 | 影响 |
|---|------|------|------|
| 1 | 运行态零信息 | 运行时面板只显示「运行中」+ 每任务淡色进度条（2.5s 轮询） | 用户必须看游戏悬浮层或日志窗才知道在干什么 |
| 2 | 启停按钮地位不突出 | 44×30 小按钮挤在左上角，与普通按钮同权重 | 这是工具唯一主操作，应是最醒目的控件 |
| 3 | 选择与看板职责混合 | 任务列表页同时承担「勾选+次数+进度」，运行中全部置灰 | 运行时没有独立的「看板」视图 |
| 4 | 任务专属设置归属割裂 | 修罗/五倍的设置放在「任务设置」页签，与任务本身分离 | 「给修罗配巫医」要离开任务列表找页签 |
| 5 | 高级设置是杂物间 | 环境/授权/方案/调试/8 组验证工具全堆在一个页签 | 8 组「按钮+结果行」长列表，难扫读 |
| 6 | 方案管理分裂两处 | 顶栏下拉快速切换 + 高级设置管理区 | 同一概念两个入口，新手困惑 |
| 7 | 状态文案单薄 | 「已停止/运行中」6 个字 | 无阶段、无战斗场次、无血蓝、无异常提示 |
| 8 | 窗口偏小 | 440×500 | 内容拥挤，新看板放不下 |

**现有数据其实够用**：任务子进程每 2s 无条件写 `debug_overlay_state.json`（任务/进度/战斗场次/血蓝/队伍），日志实时回流主进程，进度可从 config.json 直读——只是没有任何一处在面板上展示。

## 2. 设计定位

**从「设置表单 + 一个小启停按钮」升级为「仪表盘式控制台」**：

1. **一屏看清状态**：运行看板 = 当前任务 + 阶段 + 战斗场次 + 血蓝 + 队列进度 + 日志抽屉
2. **一键启停**：常驻顶栏的主按钮，视觉权重全场第一，任意页签可达
3. **设置按归属收敛**：任务专属设置进任务卡；通用归通用；系统归系统
4. **国风水墨皮肤**：深色墨色系为主（挂机场景多为夜间），印章状态章、鎏金进度、宣纸浅色模式；保留现有绿/红语义色

窗口默认尺寸 **440×500 → 720×560**（最小 600×480，用户可调）。

## 3. 信息架构

**页签（顶部横排）→ 侧边导航（左侧竖排，148px）**，5 个入口：

```
运行 看板    ← 默认页，运行态全貌
任务        ← 任务选择+次数+进度 + 各任务专属设置（合并原「任务列表」+「任务设置」）
设置        ← 原「通用设置」+ 调试信息开关
系统        ← 原「高级设置」中的 环境/授权/配置方案
诊断        ← 原「高级设置」中的验证工具（仅「调试信息」开启时显示，保持现有门控规则）
```

顶栏常驻：品牌 + 绑定角色 + 方案下拉 + 主题切换 + **启动/停止主按钮**。

导航底栏：版本号 + 授权状态点（绿=有效 / 金=临期 / 红=过期），全局可见。

### 4.1 顶栏（所有页常驻）

```

│ ◉ 啄木鸟·大话2助手   [水墨丹青·张三]      [方案▾: 日常] [🌙] [▶ 启 动 (F11)] │
```

- **主按钮**：88×34 填充按钮，绿色（accent）＝启动，运行中变**红色填充**「■ 停 止」；在途态「正在启动…」禁用；title 提示老板键 F11

- **印章状态章**：2px 实线方章，KaiTi 字体，红底白字「运行中」（-3° 微旋，呼吸脉冲 2s）；停止态灰章「待命」——品牌记忆点

  - 金：「授权即将到期（剩 N 天）」
- 队列行状态图标：✅ 已完成 / ▶ 执行中（accent 描边）/ 灰点 待执行；每行含今日进度 `done/total` 文本

## 5. 关键交互规格

| 交互 | 规格 |
|------|------|
| 启动 | 无确认，即时；按钮在途态「正在启动…」；成功后 1s 内看板切运行态 |
| 停止 | 无确认，即时（与 F11 语义一致，停止可重启，风险低）；运行中主按钮常驻红色 |
| 破坏性操作（删除方案/解绑） | 保留二击确认，升级为「确认 chip + 3s 倒计时环」视觉 |
| 方案切换 | 顶栏下拉选中即切，运行中禁用（语义不变） |
| 任务选择 | 整卡点击、步进隔离、运行中锁定（交互不变） |
| 进度刷新 | 面板轮询保留 2.5s；看板队列/今日完成同步更新 |
| 日志抽屉 | 停止态默认收起、运行态自动展开；自动跟随最新行；清空按钮；**独立吸附日志窗保留**（调试信息开启时，双屏用户用） |
| 键盘/热键 | F11 老板键不变；Esc 关闭抽屉 |

## 6. 实现依赖：运行时状态通道（唯一后端新增）

面板新状态数据（当前任务/阶段/战斗场次/血蓝）需要一个通道。两级方案：

**v1 低成本（建议先做）**：主进程新增 1s 轮询线程直读 `debug_overlay_state.json`（任务进程已无条件每 2s 写入，与调试开关无关，已核实 main.py:318），解析行文本 → 面板 push。可得：任务、进度、战斗场次、血蓝、队伍（五倍）。**阶段粒度粗**（仅「战斗中·第 N 场」可从行文本推断）。

**v2 结构化（目标形态）**：任务进程新增 `status()` 打点函数，经既有 stdout 队列发协议行 `[STATUS]{"task":"修罗","phase":"战斗","battle":37,"bars":"人 98/66 兽 99/99","progress":"45/90","syx_min":32}`：
- TaskManager 队列监听器分流：协议行 → 面板 push，不进日志窗
- 埋点位置 = 各模块既有 log 节点旁（任务进入/退出、领取、回程、寻路、巫医、战斗进入/结束、轮次完成），每模块约 5–15 行
- 面板更新延迟 ≤1s；任务结束清空状态

**前端接口**：新增 `get_runtime_status`（v1/v2 共用返回结构）。其余全部 callPython 接口**零改动**——设置语义、方案快照、验证工具、授权、绑定逻辑原样保留。

## 7. 视觉设计系统

### 7.1 色彩（语义 token，双主题）

| Token | 深色（墨色系，默认） | 浅色（宣纸） | 用途 |
|-------|------|------|------|
| --bg | `#0E1411` | `#F4F1E8` | 页面底 |
| --panel | `#161D18` | `#FBF9F2` | 卡片 |
| --panel2 | `#1D261F` | `#F0EDE0` | 控件底 |
| --border / --border2 | `#2B352E` / `#3A463E` | `#E2DCC9` / `#CFC8B0` | 描边 |
| --text / --text-dim | `#D8DED8` / `#8B948C` | `#2E2B23` / `#6E6A5C` | 正文/辅助（均 ≥4.5:1） |
| --accent / --accent-dim | `#2FBF71` / `#1F8A53` | `#177A46` / `#1E8F57` | 竹青：选中/运行/成功 |
| --gold | `#C9A15C` | `#8A6A2E` | 鎏金：进度/强调 |
| --danger | `#E5484D` | `#C23B33` | 停止/危险 |
| --seal | `#C0392B` | `#B3352F` | 印章红（运行中印章） |
| --progress-tint | `rgba(47,191,113,.12)` | `rgba(23,122,70,.10)` | 卡片进度填充 |

说明：现款 #00ff88 霓虹绿略刺眼，提案换竹青 #2FBF71（深底对比度 ≈7:1）；状态语义不变（绿=运行/成功、红=停止/危险、金=警告/进度）。悬浮层亮绿 #88FF00 保留不动（游戏画面上高可见性优先）。

### 7.2 字体

- 正文/控件：微软雅黑 13px（现状保留）
- 数字/进度/日志：Consolas（现状保留）
- 印章/品牌/页首大标题：`KaiTi, STKaiti, 楷体, serif` 装饰性使用，缺字体自动退雅黑（本地字体，不引 Google Fonts——离线桌面应用）

### 7.3 图标 / 圆角 / 间距 / 动效

- 图标：内联 SVG，统一 1.5px 描边、18px（导航）/ 14px（行内）；禁 emoji（现有方案管理图标风格延续）
- 圆角：卡 8px / 按钮 6px / 印章 4px
- 间距：4/8px 节奏；卡间距 8px、组间距 12px、页面 padding 14px（高密度仪表盘档）
- 动效（Subtle）：过渡 150–200ms；进度条 0.4s ease；运行脉冲 2s；`prefers-reduced-motion: reduce` 全部禁用
- 焦点：所有交互元素 2px accent outline（offset 2px），键盘可达
- 反馈：按下反馈 80–150ms（brightness/opacity，不改变布局边界）

## 8. 边界与异常态

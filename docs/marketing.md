# 啄木鸟 · 产品优势与卖点（对外推广素材）

> 定位:不是「按键精灵式」通用脚本,而是专为大话西游2经典版日常任务打磨的**任务级托管助手**——点一下启动,五环/客栈/修罗/五倍/玄枢轶闻整条链路自动跑完,带队、补人、喊话都替你干了。

## 市面同类产品现状(对比基准)

| 类型 | 代表 | 典型能力 | 短板 |
|---|---|---|---|
| 通用按键脚本 | 按键精灵 | 录制/回放鼠标键盘 | 无游戏场景认知,界面一改就废;不认任务状态 |
| 老牌平台化辅助 | 简单游、白日梦 | 早年功能较全 | 历史遗留产品,对现版本经典版维护少 |
| 单体小工具 | DevilKing 刷真元、垂云叟助手、答题器 | 单一功能:喊话/答题/加血蓝/自动点自动 | 各管一摊,拼不出一条完整日常 |
| 个人易语言脚本 | 「多开无限自动」等 | 自动战斗+血蓝+定时 | 个人维护、无人跟进;停留在挂机辅助层 |
| 工作室内存级外挂 | 机器队长类 | 后台多开 | 封号重灾区、无售后、灰色交易风险 |

> 注:同类产品信息来自公开下载站/博客的宣传口径,仅作能力定位参考。

## 差异化优势

### 1. 整条任务链路自动化,而不是单一功能点

五环、客栈、修罗、五倍、玄枢轶闻,每条任务从领取 → 跑图 → 战斗 → 交任务 → 回城**全程闭环**;每条任务可独立设置次数,**当天进度按角色持久化,停止/重启不重置**。市面脚本大多是「帮你点自动、帮你加血蓝」的挂机级辅助,啄木鸟是「把今天日常做完」的任务级托管。

### 2. 队长能力自动化(市面几乎空白)

- **自动补人**:开队缺人自动从申请列表放人,不合格自动换
- **缺人自动喊话**:每 30 秒自动喊话招募,修罗还会按你设置的种族要求自动拼文案
- **检查队伍**:修罗最少人数/必须种族,五倍固定 5 人
- **被拒自愈**:领取被拒(五倍「前途凶险…」/修罗「战斗力异常…」)自动重回补人循环

当队长不用盯屏幕:队伍自己会满员、自己会出发。

### 3. 稳定性是工程化出来的,不是「能跑就行」

- 每轮判定只截一帧、模板匹配限定搜索条带(实测单次匹配 25ms → 1.5~5.7ms)、OCR 前置像素差分跳过(148~311ms → 7ms)
- 相似界面双模板比分数,杜绝「解散队伍误点离开队伍」「第2回合误判第1回合」这类翻车
- 进场/退场防抖窗口经实测校准,不会因回合间隙误判结束

挂机类工具最值钱的指标就是「长时间跑不出错」,这是啄木鸟最大的护城河。

### 4. 断点续做 + 高性能模式

- 任务进度按角色持久化,程序重启不重跑
- **高性能模式**:固定位置缓存点击、失败自动回退识别,缓存坐标持久化,重启后无需重新识图
- 摄妖香按角色记忆(1 小时一次,持续运行自动续用)

### 5. 用户不用懂技术,出问题自己能排查

- 可视化控制面板(任务列表/任务设置/通用设置/高级设置四个页签),开关即配置
- 高级设置里每个链路(回程/领取/巫医/清屏/喊话)**一键验证**,点一下就知道哪条链路识别正常
- 悬浮任务信息 + 吸附日志窗,运行状态一眼可见

市面脚本出问题只能找作者;啄木鸟把排查工具做进了面板。

### 6. 多开友好

检测到多个游戏窗口时启动弹框选择操作对象,按标题中的账号 ID 记住,**游戏更新版本号也不失效**;「使用环境」可查看绑定并随时解除重选。

### 7. 开箱即用 + 授权体系成熟

- GitHub Actions 自动打包 exe,下载 zip **解压即用**,不用装 Python、不用配环境
- 卡密授权:免费版直通,付费卡密在线校验,面板显示授权状态与到期时间,支持解绑换绑
- 免费版即可完整体验任务功能,先试后买

### 8. 更安心的操作方式

前台模拟键鼠操作:**不读内存、不改包、不注入**,原理上处于比内存级外挂更低的风险区间;点击节奏含拟人化设计,降低行为特征。(如实提示:任何第三方辅助均有封号风险,不承诺「绝对防封」,建议小号先观察。)

## 目标用户

- **上班族/休闲玩家**:白天没时间,晚上挂完日常
- **五开/多开玩家**:队长号交给助手,其余号手动
- **半脱产玩家**:重复日常交给工具,精力留给任务之外的内容
- **不想学写脚本的普通玩家**:面板操作,零编程门槛

## 手机端规划(预告)

PC 端先行,**手机端(Android/iOS)已在规划中**;同一套任务逻辑与授权体系,后续同一卡密两端通用。现在入手锁定首发用户权益。

## 常用疑虑回答

- **会封号吗?** 任何辅助都有风险,不承诺绝对安全;但前台模拟+拟人化节奏属于风险较低的一类,可先用小号观察。
- **需要会写脚本吗?** 不需要,面板点开关即可。
- **电脑配置要求?** 普通 Windows 10+ 即可,工具自带低开销优化(单帧复用/条带匹配/差分跳过)。
- **游戏要全屏吗?** 窗口模式运行(已适配水墨主题 1378×831),运行期间游戏窗口保持前台。

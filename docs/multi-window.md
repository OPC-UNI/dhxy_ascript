# 多窗口多方案执行（设计定稿）

> 状态：已与用户确认并完成实现（2026-11-22）；第 1–5 阶段代码与单元
> 测试已落地，待双窗口实机验证。目标：一个「啄木鸟」控制面板同时管理
> N 个游戏主窗口，每个窗口按自己的角色方案并行执行不同任务；窗口间
> 完全独立。

## 1. 范围

- 执行单元 = 游戏主窗口（一窗口 = 一角色）；窗口内部可继续使用「组号」
  （一窗口多 Tab），Tab 不升级为独立执行单元。
- 多窗口真并行，每个运行窗口一个 worker 子进程；单窗口失败/关窗只停自己。
- 明确不做：跨窗口组队协同；最小化运行；抢前台兜底；跨安装共享方案/
  授权；硬编码窗口数上限。

## 2. 运行模型

| 层 | 职责 |
|---|---|
| 主进程 | UI、窗口枚举、启停调度、授权校验、单实例锁、`config.json` 唯一写者 |
| 每窗口 worker 子进程 | 只服务自己的角色/窗口，沿用现有 spawn + 停止升级强杀 |

目标注入：worker 启动时进程内固化 `role_id + hwnd`：

- `game.set_process_target(..., strict=True)`：`find_main_window()` 只返回
  该 hwnd 的窗口；句柄失效返回 None（不回退其他窗口）。
- `user_data.set_process_role(role_id)`：`current_role_id()` 直接返回该角色，
  清空 30s 缓存；`role_settings` / `char_key` / 状态文件全部落到该角色。
- 组号（tab_group）/pass/team/battle/OCR 引擎等进程级全局状态因此天然隔离。

主进程选中行（舰队视图的选中窗口）同样通过目标注入驱动 `find_main_window()`：
选中窗口关闭时保持选中角色（不回退其他窗口），由 UI 显示灰行并禁用依赖
窗口的操作；窗口恢复后自动回真。现有「绑定窗口关闭自动改绑」在多窗口模式
移除。

写入边界：worker 只写 `data/<角色ID>/` 下状态文件（原子替换），禁止写
`config.json` 全局绑定；主进程是 config 唯一写者。

## 3. 绑定与调度

- 自动枚举所有游戏主窗口，按「服务器 + 角色名（ID）」成行；勾选状态按
  角色 ID 持久化；新角色默认不勾选，曾勾选过的恢复。
- 行集合 = 检测到的窗口 ∪ 已勾选但未检测到的角色（灰行）∪ 未登录窗口（灰行）。
- 选中行 = 主进程「当前窗口」：设置页、方案、验证、成就、清屏、退出游戏
  都作用于它。
- 方案 = 该角色自己的 active 方案（按角色隔离），运行中的角色设置/方案只读。
- 启停：全部启动/全部停止 + 行内独立启停；全部停止不二次确认；启动错峰
  1–1.5s；每次启动动作只做一次在线授权校验。
- 老板键 = 只停不起（全部停止）。
- 同角色互斥：实例内一角色一运行窗口；跨实例按角色 ID 命名互斥，先启动
  者占用，第二实例对应行显示「另一实例运行中」并禁启。
- 单实例：同一安装目录锁，二次启动唤起已有面板；不同目录允许并行。
- 关窗只停该窗口、不自动重启；「退出游戏」只作用选中窗口且先停其任务。
- 失败告警按窗口独立升级（连续 3 次 → 一条 ERROR），带角色前缀。

## 4. UI：窗口为轴（2026-11-22 v2，已确认）

> 实机效果：`docs/ui-mockups/multi-window-v2.png`（双窗口）、
> `docs/ui-mockups/single-window-v1.png`（单窗口）；早期两行 Tab 设计稿
> 保留在 `docs/ui-mockups/window-tabs-v1.html`。旧「舰队列表做主页」的方案
> 被否决：窗口行信息拥挤、跨窗口进度合计无意义、主次信息混乱。v2 把
> 「窗口」提为全局主入口。

**信息架构**

- **顶栏内嵌窗口 Tab**（全局上下文，省去独立 40px 一行）：切 Tab = 切当前
  窗口，运行 / 任务 / 组号 / 设置 / 成就 / 诊断整页跟随；消息页保持全局。
- Tab = 状态点 + 角色短名 + 该窗口今日进度；顺序固定（注册表 seq），
  启动/停止/选中都不重排。≥2 个可选窗口才显示；单窗口隐藏，顶栏恢复
  「多开 N 窗口 · M 运行中 ›」管理入口。
- Tab 集合 = 已勾选角色 ∪ 当前选中 ∪ 运行中（勾选/反选即时增删 Tab；
  当前选中/运行中的窗口即使反选也保留，避免失去上下文）；已勾选的关闭
  窗口保留灰色 Tab（配置仍可达）；未勾选且非当前/非运行的窗口只在管理页
  出现；未登录窗口也只在管理页出现。
- **顶栏**：左侧 = 窗口 Tab（≥2 窗口）或「多开 N 窗口 · M 运行中」入口
  （单窗口），右侧仅「全部启动 / 全部停止」；主题切换移到系统页；方案
  下拉在当前窗口状态卡（窗口属性）。
- **运行页 = 当前窗口视角**：状态卡（印章 / 名称+ID / 阶段·任务·场次·队伍 /
  今日进度 / 启动本窗口·停止本窗口 / 方案）+ 该窗口任务队列 + 该窗口日志
  （默认「本窗口」，可切「全部」）。**页面内不出现任何跨窗口进度合计。**
- **页面归属只归一个层级**（2026-11-22 用户确认）：
  - 角色级（跟随窗口 Tab）：运行 / 任务 / 组号 / 设置 / 成就 / 诊断。
  - 软件级（不跟 Tab）：消息 / 系统；这两页 Tab 条标「全局页」并降透明，
    页面顶部提示「软件级 · 不随窗口 Tab 切换」。
  - 配置方案管理从系统页移到**设置页顶部**（方案是角色设置的快照）；
    运行页状态卡只保留快速切换下拉。系统页仅剩使用环境 / 授权 /
    显示与调试 / 关于；深浅主题切换也收进系统页「使用环境」。
- **多开管理** = Tab 条右侧「管理」（单窗口时从顶栏「多开 N 窗口」进入）
  的二级页，不进侧边栏：只负责「是否绑定参与多开」——整行点击或勾选框切换，
  每行显示运行态、进度与异常徽章；行内不再放方案/启动/配置（方案在运行页
  状态卡，启停在顶栏/状态卡，任务配置走 Tab + 任务页）。这里也不做跨窗口
  进度合计，只保留「N 个窗口 / M 个运行中 / K 个已勾选」计数。

**状态与交互**

- 行状态：运行中（阶段色徽章）/ 未启动 / 窗口已关闭 / 未登录 / 同角色占用 /
  另一实例运行中 / 未勾选 / 错误红点。
- 1s 枚举刷新 + 启停后即时刷新；点击 Tab/管理行选中；顶栏主按钮 = 全部启停；
  状态卡按钮 = 本窗口启停；老板键只停不起。
- 托盘 = 显示面板 / 全部停止 / 彻底退出。
- 系统页移除「当前窗口/切换窗口」展示与「配置方案」管理区（切换统一走
  Tab 条 / 多开管理；方案管理移到设置页）；启动选窗弹框移除；旧绑定
  角色迁移为默认勾选 + 选中行。
- 组号入口显隐跟随当前窗口：该角色组号开关 + `group_detected` + 该窗口实时
  已登录 Tab ≥ 2；切换窗口立即重算。运行中的 A 选中时入口仍显示但只读。

## 5. 数据归属

| 数据 | 键控 | 写者 | 位置 |
|---|---|---|---|
| 方案/设置 | 角色 | 主进程 | `data/<角色ID>/settings.json`、`schemes.json` |
| 任务进度/摄香/清屏/统计 | 角色 | 各 worker | `data/<角色ID>/state.json` 等 |
| 运行时阶段/队伍/血蓝 | 角色 | worker | `data/<角色ID>/debug_overlay_state.json` |
| 勾选/选中行/Tab 顺序 | 角色/全局 | 主进程 | `config.json multi_window_state` |
| 主进程当前窗口绑定 | 单值 | 主进程 | `config.json bound_window_id`（保留） |
| 日志 | 角色 + 日期 | worker | `logs/<日期>/<角色ID>.log` |
| 系统日志 | 日期 | 主进程 | `logs/<日期>/system.log` |
| 授权 | 安装目录 | 主进程 | 现有 license 记录 |
| 跨实例角色锁 | 角色 | worker | 命名互斥（无文件） |

## 6. 安全与并发约束

- 静默模式是多窗口硬前提（任一参与角色关闭静默时只允许单窗口运行）；
  一律不抢前台，静默失败跳过并记 WARN/ERROR。
- 运行期间禁用会 `SetForegroundWindow` 的诊断按钮。
- 遮挡允许；最小化即停该窗口并提示。
- 一角色一运行窗口（实例内 + 跨实例命名互斥）；停止沿用
  stop_event/pipe → 3s join → terminate → kill。
- 同一安装目录单实例（不同目录可并行）；第二实例触发显示事件后退出。
- 每 worker 独立 OCR 引擎，资源随窗口数线性增长；不设上限。
- 选中窗口关闭时保持选中角色（灰行，设置页只读），不自动跳到其他
  窗口；组号入口显隐 = 选中角色组号开关 + `group_detected` + 该窗口
  实时已登录 Tab ≥ 2。

## 7. 验收

- 两窗口不同方案并行；两个窗口都开组号并各自切 Tab。
- 关窗/最小化只停该窗口；其余继续。
- 全部启停、单行启停、老板键只停、授权一次校验。
- 同角色重复窗口、跨实例同角色、同目录二次启动、不同目录双实例。
- 按角色日志、抽屉过滤/合并、运行中方案只读、旧绑定迁移、单窗口回归。
- 错误红点与按窗口告警。

修罗链路
与实际流程一致、时序无额外延时，且都不改变任务状态：回程=定位回城符不点击；领取=点击领取按钮开对话框、选项仅定位不点击、点屏幕中间关闭；巫医=走位到 NPC、定位后点击打开对话框（医治选项由战斗线程处理）；组号巫医=巫医完整链路后逐个切换队员 Tab 点击其医治对话框并切回队长（需窗口内 ≥2 个已登录 Tab，开关状态不校验）；修理=走位到洛阳城修理 NPC、点击打开对话框（两套弹窗按文案→选项映射，选项由验证流程自行点击，与战斗线程等效）；组号修理=修理完整链路后逐个切换队员 Tab 点击其修理对话框并切回队长（需 ≥2 个已登录 Tab）。静默修罗领取/静默修罗巫医/静默修罗回程=与领取/巫医/回程验证同流程，但全程静默点击（不移动物理鼠标、不激活游戏窗口，游戏窗口可不前台），用于验证静默通道跑通完整链路。任务运行中不可验证。
五倍链路

队伍
检查队伍信息=走真实队伍检查链路（与任务检查同一套逻辑）：打开队伍面板 → 队长判定（双模板比分数+复核）→ 5 固定区域成员扫描（空位模板截断、种族/等级逐区识别）→ 关闭面板，全程真实点击（组队按钮/面板/关闭按钮）。创建队伍=真实执行创建链路：组队菜单 → 队伍信息判定（已组队直接返回不操作）→ 点击「创建队伍」→ 校验队伍面板打开并关闭，未组队时会真实创建队伍（与任务「自动创建队伍」开关同一套链路，仅手动测试/确认识别用）。测试归队=读取当前位置判定是否在轮回司（打日志）→ 在轮回司则自动归队：开面板 → 身份判定 → 点「回归队伍」按钮传送回队长（按约定假设战斗已结束，不判战斗）。检查队伍暂离=开面板逐成员区域找「召回」标记（出现即该队员暂离），不改变队伍状态。请离暂离成员=真实执行请离链路：找召回标记 → 点选该成员卡 → 「请离队伍」按钮 → 请离并校验，会真实踢出队员（一次一名，仅手动测试/确认识别用）。组号自动归队=先检查暂离 → 暂离成员昵称与队员 Tab 标题角色名模糊匹配 → 匹配到则逐个切过去点「回归队伍」归队（需窗口内 ≥2 个已登录 Tab，开关状态不校验）。测试场景由用户手动操作，全程真实点击与真实切 Tab。任务运行中不可使用。

静默点击
不移动物理鼠标、不激活游戏窗口，直接向游戏窗口投递一次消息点击（游戏画面中心），用于验证「游戏窗口不在前台」时能否后台点击——左键已实测有效，可行性确认后部分原走鼠标的点击可切换为静默点击。右键投递 WM_RBUTTONDOWN/UP（游戏世界右键会弹操作菜单，可直接观察）。点击后自动对比前后画面差异给出疑似生效/未生效，请同时观察游戏画面（左键看人物是否走向画面中心，右键看是否弹出操作菜单）做最终确认。静默回蓝=右键投递窗口坐标 (1316,105) 一次；静默回血=右键投递窗口坐标 (1316,87) 一次；均只投递不做判定，结果请自行观察血蓝条变化。静默按键=投递组合键消息一次（Alt 组合走 WM_SYSKEYDOWN/UP、Ctrl 组合走 WM_KEYDOWN/UP，实测：Alt+C/Alt+E/Alt+5/Alt+6 有效，Ctrl+Tab 与 Enter 无效），生效信号：Alt+C 人物降落/位置显示刷新、Alt+E 背包打开、Alt+5/Alt+6 屏蔽飘字提示、Alt+U 飞行驭器面板打开（高性能+静默任务的打开路径）、Ctrl+Tab 切换 Tab、Enter 聊天输入框开关。实测结论：Alt 组合/Enter+WM_CHAR/WM_CHAR 中文字符注入有效，Ctrl+Tab 无效（切 Tab 维持键盘门控），WM_PASTE/WM_UNICHAR 无效（子窗口枚举无标准 Edit 控件）。静默字符 WM_CHAR=投递「测」字符消息，请先手动点开游戏聊天输入框再测。请先把控制窗口移到游戏窗口上层遮挡（或切到其他窗口）再点击。任务运行中不可验证。

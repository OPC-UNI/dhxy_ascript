修罗链路
与实际流程一致、时序无额外延时，且都不改变任务状态：回程=定位回城符不点击；领取=点击领取按钮开对话框、选项仅定位不点击、点屏幕中间关闭；巫医=走位到 NPC、定位后点击打开对话框（医治选项由战斗线程处理）；组号巫医=巫医完整链路后逐个切换队员 Tab 点击其医治对话框并切回队长（需窗口内 ≥2 个已登录 Tab，开关状态不校验）。静默修罗领取/静默修罗巫医/静默修罗回程=与领取/巫医/回程验证同流程，但全程静默点击（不移动物理鼠标、不激活游戏窗口，游戏窗口可不前台），用于验证静默通道跑通完整链路。任务运行中不可验证。
五倍链路
与实际流程一致、时序无额外延时，且不改变任务状态：领取=走位到宝象国领取点 → 点击领取入口（领取任务按钮/降魔侍卫）打开对话框 → 选项「除魔卫国，义不容辞」仅定位不点击 → 点拒绝选项「事态严重，我等退散」关闭对话框；回程=定位回城符不点击（回城符模板待提供，缺失时报模板未提供）；巫医=走位到巫医 NPC、定位后点击打开对话框（医治选项由验证流程自行点击，与任务进程中战斗线程点击行为等效）；白龙马模板=按任务流程实际点击候选（找全部候选→逐一真实点击→误点对话框自动关闭→开打对话出现即停止并停留，请手动关闭对话框）。任务运行中不可验证。
清屏
执行真实清屏流程：激活游戏窗口 → 按 Alt+6 屏蔽非队伍玩家 → 按 Alt+5 屏蔽摊位（真实按键，可能短暂取消再开启），结束时两个屏蔽均处于开启态，与任务启动清屏结果一致。游戏窗口未在前台时跳过并提示。任务运行中不可验证。
喊话
向游戏聊天发送一次喊话验证 Enter→输入→Enter 链路：五倍发固定内容「百次五倍来人，效率队」；修罗发按必须种族拼装的文案（如「百次修罗来人，效率队，来男人」）。发送后请查看游戏公屏是否出现消息。任务运行中不可验证。
模板与坐标
机关模板：对当前游戏画面逐一测试黄/蓝/红三个机关模板，打印全帧最佳匹配度与位置日志（只读不点击），请将游戏画面停在封印机关场景再测试。坐标：读取游戏左上角当前地图名与坐标并打印日志（只读）。两项任务运行中也可使用。
截屏通道
对比 PrintWindow(3)/PrintWindow(0)/窗口 BitBlt/全屏 BitBlt 四条截屏通道并记录环境事实（显卡/DWM/进程提权/兼容模式），逐行写入本地日志文件与面板日志抽屉，用于定位黑屏/识别全失效问题。只读不点击（任务未运行时额外尝试置前游戏窗口复测），约 10 秒。任务运行中也可诊断（跳过置前复测）。
枚举游戏主窗口下所有可见子窗口（hwnd/类名/矩形，只读）逐行写入日志——定位聊天输入框等子控件用，为静默文本输入通道排查提供依据。任务运行中也可使用。
静默点击
不移动物理鼠标、不激活游戏窗口，直接向游戏窗口投递一次消息点击（游戏画面中心），用于验证「游戏窗口不在前台」时能否后台点击——左键已实测有效，可行性确认后部分原走鼠标的点击可切换为静默点击。右键投递 WM_RBUTTONDOWN/UP（游戏世界右键会弹操作菜单，可直接观察）。点击后自动对比前后画面差异给出疑似生效/未生效，请同时观察游戏画面（左键看人物是否走向画面中心，右键看是否弹出操作菜单）做最终确认。静默回蓝=右键投递窗口坐标 (1316,105) 一次；静默回血=右键投递窗口坐标 (1316,87) 一次；均只投递不做判定，结果请自行观察血蓝条变化。静默按键=投递组合键消息一次（Alt 组合走 WM_SYSKEYDOWN/UP、Ctrl 组合走 WM_KEYDOWN/UP，实测：Alt+C/Alt+E/Alt+5/Alt+6 有效，Ctrl+Tab 与 Enter 无效），生效信号：Alt+C 人物降落/位置显示刷新、Alt+E 背包打开、Alt+5/Alt+6 屏蔽飘字提示、Ctrl+Tab 切换 Tab、Enter 聊天输入框开关。实测结论：Alt 组合/Enter+WM_CHAR/WM_CHAR 中文字符注入有效，Ctrl+Tab 无效（切 Tab 维持键盘门控），WM_PASTE/WM_UNICHAR 无效（子窗口枚举无标准 Edit 控件）。静默字符 WM_CHAR=投递「测」字符消息，请先手动点开游戏聊天输入框再测。请先把控制窗口移到游戏窗口上层遮挡（或切到其他窗口）再点击。任务运行中不可验证。
